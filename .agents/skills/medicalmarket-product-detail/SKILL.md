# 메디컬마켓 제품 상세 등록 및 보강

1. 제조사와 모델명으로 공식 목록·상세 페이지를 확인한다. 기존 공개 제품과 비공개 초안을 함께 조회한다. 띄어쓰기, 하이픈, 제조사 표기 차이는 정규화하고, 세부 모델·버전은 구분한다. 여러 모델이 묶여 있거나 후보가 여럿이면 관리자 비교 대상으로 남긴다.
2. 일치 제품에 해당 공급업체 관계가 없으면 연결 후보로 표시한다. 신규 모델은 공식 원문 주소와 함께 비공개 초안으로 저장한다. 기존 분류표에서 가장 적합한 대표 카테고리를 미리 선택하고 관리자 수정값을 보존한다.
3. 공식 자료에서 확인한 사용 목적, 구조·측정 방식, 주요 사양, 결과지, 설치 조건, 기본 구성품과 선택품을 제품에 맞게 다시 작성한다. 구매자가 견적 전에 확인할 항목을 덧붙인다. 확인되지 않은 성능과 옵션은 단정하지 않는다. 공개 상세 본문에는 사양·이미지 출처 문구와 제조사 원문 링크를 넣지 않는다. 원문 주소는 관리자 검토 기록에 보관한다.
4. 공식 상세 페이지에서 해당 모델에 속한 이미지 원본을 확보한다. 탭과 펼침 영역의 이미지도 확인하고, 원본 파일을 확보하기 어려우면 해당 이미지 영역을 캡처한다. 중복 및 다른 모델의 이미지를 제외하고 메디컬마켓 자체 스토리지에 저장한다. 결과지와 사양 도표는 글자가 읽히는 해상도를 유지한다. 본체 사진을 검색 카드의 대표 이미지로 지정하고, 모델 이미지 전체를 갤러리 썸네일로 등록한다. 본문 이미지도 같은 저장본을 사용해 관련 문단 아래에 배치한다.
5. 이미지 저장과 제품 수정은 권한이 있는 메디컬마켓 API를 사용한다. 기존 제품을 수정할 때는 제품 ID, 현재 버전과 공개 상태를 확인해 같은 제품을 갱신한다. 신규 초안은 관리자 승인 후 공개한다.
6. 저장 후 제품 API에서 대표 사진, 갤러리와 상세 본문을 확인한다. 공개된 제품은 로그인 없이 모델명으로 검색해 카드 사진을 확인하고, 카드 클릭과 상세 주소 새로고침으로 본문과 이미지가 열리는지 검사한다. 썸네일을 클릭해 실제 사진이 열리는지도 확인한다.
