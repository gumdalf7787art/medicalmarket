메디컬마켓 저장소 루트의 [팀원 업무 지침](../../../docs/product-guide-editorial.md)을 읽고 요청받은 장비와 작업 범위를 확인한다.

1. 제품 검색 API로 후보를 찾고 상세 응답의 id, 공식명, 모델, 대표 사진, 갤러리, 상세 설명 이미지(guidePhotos.details)를 확인한다. 동명이거나 규격이 다른 제품은 모델·제조사까지 대조한다.
2. 제품과 주제로 기존 안내 글을 조회한다. 개정 요청이면 기존 주소와 revision을 유지하고, 별도 질문을 다루는 신규 글이면 고유 주소를 정한다.
3. 제품과 독자의 질문에 맞춰 제목·요약·본문·사진 순서를 작성한다. 중복을 제외한 제품 이미지 2~4장을 선택하고, 상세 설명에 제품 이미지가 있으면 활용한다. 확인한 근거와 미확인 사항은 원고 밖의 작업 보고에 남긴다.
4. 원고나 기획 요청은 해당 산출물을 전달한다. 저장·발행 요청이면 [API 계약](../../../docs/product-guide-api.md)에 따라 전용 토큰으로 API를 호출하고 응답과 저장 상태까지 확인한다. 토큰이 연결되지 않았으면 저장·발행이 보류된 이유를 보고한다. 이미 공개된 글의 수정안을 요청받았을 때 원고를 보관하려고 published=false로 덮어쓰면 기존 글이 비공개가 되므로 수정안만 전달한다.
5. 공개 발행 후 로그인 없는 글 주소, 모델명 검색, 해당 제품의 견적 요청 링크를 확인한다. 완료 보고에 제품 ID, 글 제목, 저장 상태, 확인 결과를 적는다. API 호출이 실패했으면 작성 완료와 발행 완료를 구분한다.
